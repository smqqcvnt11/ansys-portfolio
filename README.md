# Ansys Simulation Portfolio
Портфолио инженерных расчётов и наработок в **Ansys**. Здесь будут собраны модели, скрипты, отчёты и результаты с объяснением принятых решений.
Engineering simulation projects in Ansys, with reproducible workflows, validation and documented results.
## Проекты
Портфолио находится на этапе наполнения. Первый проект будет добавлен после подготовки материалов и проверки расчёта.

## Как оформляется каждый проект
1. **Задача:** что исследуется и на какой инженерный вопрос отвечает расчёт.
2. **Исходные данные:** геометрия, материалы, единицы измерения, источники и допущения.
3. **Модель:** версия Ansys, тип анализа, сетка, контакты, нагрузки и граничные условия.
4. **Проверка:** сходимость, чувствительность к сетке, сравнение с аналитикой или справочными данными, где применимо.
5. **Результаты:** изображения с легендой и единицами, графики, ключевые численные значения.
6. **Выводы:** интерпретация результатов, ограничения модели и следующие шаги.
7. **Воспроизведение:** порядок запуска, необходимые файлы и настройки.
## Организация материалов
Для новых проектов используем следующую структуру; папки добавляются вместе с реальными материалами:
```text
projects/
  project-name/
    README.md       # постановка задачи, методика и выводы
    model/          # исходные файлы модели
    scripts/        # скрипты построения и обработки
    figures/        # изображения, схемы и графики
    reports/        # итоговые отчёты
    data/           # компактные таблицы исходных данных и результатов
```
Каждое обновление сопровождается понятным описанием изменений. Объёмные архивы и файлы результатов размещаются отдельно с указанием версии и ссылки в описании проекта.
## Статус материалов
Черновые, проверенные и завершённые расчёты явно отмечаются в описаниях проектов. Ограничения и неподтверждённые предположения документируются вместе с результатами.
